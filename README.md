# Welcome to the codebase of a KU01-project!

A project where I code art and hope that it represents some "wish" of mine.

## Dependencies

- C++ compiler (e.g. g++)
- Python3 (to get data from PNG)
  - PIL (Pillow)
- Netpbm package (to convert from .ppm to .png; not necessary if conversion not needed)

The latest versions are recommended but earlier ones might work too.
